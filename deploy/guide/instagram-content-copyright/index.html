인터넷에서 찾은 이미지를 사용할 때

검색에서 찾은 이미지는 대부분 누군가 만든 저작물입니다. 사용 가능 여부는 이미지를 올린 사이트의 이용 조건에 따라 다르므로, 조건이 명시되지 않았다면 쓰지 않는 편이 안전합니다.

다른 사람의 사진

  • 사진의 저작권은 촬영한 사람에게 있을 수 있다
  • 사진 속 인물의 얼굴이 나온다면 별도로 인물 관련 권리를 고려해야 할 수 있다
  • 고객이나 직원 사진은 사용 범위(어디에 올리는지)까지 동의받기

폰트

무료로 보이는 폰트도 상업적 이용(가게 홍보 포함)이 제한될 수 있습니다. 폰트 배포처의 라이선스 안내에서 상업 사용 가능 여부를 확인하세요.

음악

릴스나 영상에 쓰는 음악은 플랫폼에서 제공하는 음원 사용 조건이 따로 있고, 계정 유형(개인/비즈니스)에 따라 사용 가능 범위가 다를 수 있습니다. 현재 조건은 Instagram의 공식 안내에서 확인하세요.

AI 이미지

  • 도구마다 상업적 이용 조건이 다르다
  • 결과물이 기존 작품과 비슷해질 수 있다
  • 실존 인물이나 유명 캐릭터를 의도적으로 흉내 내게 하지 않는다

AI 결과물의 권리 관계는 도구와 국가에 따라 다르게 다뤄질 수 있어 이용 약관을 직접 읽어 보는 것이 좋습니다.

브랜드/상표

다른 가게나 브랜드의 로고를 그림에 넣거나, 비슷한 이름을 쓰면 오해나 분쟁이 생길 수 있습니다. 우리 가게 이름을 정할 때도 같은 업종에 비슷한 이름이 있는지 확인해 보세요.

고객 사진

손님이 올린 후기 사진을 재게시하려면 작성자의 허락을 받고, 가능하면 서면(메시지 캡처 포함)으로 남겨 두세요.

출처 표기만 하면 되는가?

출처 표기는 예의일 수 있지만 사용 허락을 대신하지 않습니다. 허락이 필요한 자료는 출처를 적어도 허락을 받아야 합니다.

게시 전 권리 확인 체크리스트

  • 이미지는 직접 만들었거나 사용 허락이 있다
  • 폰트는 상업적 이용이 가능한 것이다
  • 음악은 현재 플랫폼 조건에서 사용 가능한 것이다
  • 사진 속 사람에게 동의를 받았다
  • 로고·상표를 허락 없이 쓰지 않았다
  • AI 도구의 이용 약관을 확인했다
주의

위 내용은 일반적인 안내이며 법률 자문이 아닙니다. 분쟁 가능성이 있다면 전문가(변호사, 변리사 등)에게 확인하세요.

이 글에서 기억할 내용

  • 인터넷에서 찾은 이미지는 기본적으로 자유롭게 쓸 수 있다고 가정하지 않는다.
  • 폰트·음악·AI 이미지는 각 서비스의 이용 조건을 확인한다.
  • 출처 표기만으로 사용 허락이 되는 것은 아니다.
  • 확실하지 않으면 직접 만든 자료나 사용 허락이 명확한 자료를 쓴다.
