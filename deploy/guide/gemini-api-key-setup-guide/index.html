Gemini API 키 넣는 방법과 오류가 날 때 해결하기

인스타툰 연재실의 대본·캡션 만들기는 사용자가 직접 발급한 Google Gemini API 키로 동작합니다. 키를 넣는 위치, 자주 보이는 오류 메시지의 뜻과 해결 순서, 키를 안전하게 다루는 방법을 정리했습니다.

키를 받아서 넣는 순서

  1. Google AI Studio의 API 키 페이지(aistudio.google.com/apikey)에 접속해 Google 계정으로 로그인한다.
  2. "API 키 만들기(Create API key)"로 키를 만들고 복사한다.
  3. 인스타툰 연재실 화면 위쪽의 "API 키 설정"을 열어 "Gemini API 키" 칸에 붙여 넣고 "저장"을 누른다.
  4. 오른쪽 위에 초록 점과 "Gemini 연결됨"이 보이면 완료다.

Gemini는 이 도구에서 대본, 기획, 캡션 같은 글을 만드는 데에만 쓰입니다. 그림은 사용자가 ChatGPT 같은 외부 이미지 도구에서 직접 만듭니다. 키 발급 화면과 무료 사용 범위는 Google이 바꿀 수 있으니 AI Studio의 현재 안내를 확인하세요.

모델 이름 칸은 어떻게 하나

"대본·기획 모델" 칸에는 기본값이 들어 있습니다. 보통은 그대로 쓰면 됩니다. 모델 이름 관련 오류가 나면 AI Studio에 표시되는 현재 사용 가능한 모델 이름으로 바꿔 저장해 보세요. 어떤 이름이 사용 가능한지는 시기와 계정에 따라 다를 수 있습니다.

오류 메시지별 원인과 해결

보이는 메시지(요약)뜻해 볼 것
API 키가 올바르지 않아요키가 잘못 복사되었거나 삭제된 키"API 키 설정"에서 키를 다시 복사해 붙여 넣기. 앞뒤 공백이 들어가지 않았는지 확인
Gemini 사용 한도를 넘었어요무료 또는 현재 요금제의 사용량을 넘음메시지에 안내된 대로 잠시 기다리거나 다음 날 다시 시도. 모델에 따라 무료 키로 쓸 수 없는 경우도 있어 AI Studio에서 요금제와 한도를 확인
Gemini 서버가 지금 붐벼요일시적인 서버 혼잡잠시 뒤 같은 버튼을 다시 누르기
API 키 권한 문제예요키 권한, 결제, 지역 제한 등AI Studio에서 키 상태와 결제·지역 조건 확인
업종 선택 전 "인스타툰 만들기"가 눌리지 않음필수 입력(업종)이 비어 있음업종 칩을 하나 선택하거나 직접 입력
실전 팁

그래도 해결되지 않으면 "백업 저장"으로 작업을 파일로 받아 둔 뒤 페이지를 새로고침해 보세요. 도구의 "막힐 때" 메뉴에도 증상별 해결 순서가 있습니다.

키를 안전하게 쓰는 방법

  • 키는 이 도구를 열어 둔 내 브라우저의 저장 공간에 보관되며, 운영자의 서버로 보내지 않습니다. AI 기능을 쓸 때 브라우저가 Google의 Gemini API로 직접 요청을 보냅니다.
  • 집이나 사무실처럼 본인만 쓰는 기기에서 사용하세요. 공용 컴퓨터에서는 사용 후 키 칸을 비우고 저장하거나 브라우저 데이터를 지우세요.
  • 키를 메신저, 게시글, 스크린샷에 노출하지 마세요. 노출됐다면 AI Studio에서 키를 삭제하고 새로 만드세요.
  • 필요하지 않은 확장 프로그램이나 신뢰할 수 없는 사이트에서 이 페이지를 열지 마세요. 브라우저에 저장된 값은 같은 브라우저의 악성 프로그램에 노출될 수 있습니다.
주의

"API 키를 알려 주면 대신 설정해 준다"는 요청은 따르지 마세요. 키는 타인에게 주는 비밀번호와 같습니다.

보낸 내용은 어디로 가나

AI 기능을 쓰면 입력한 업종, 가게 이야기, 프로필, 선택한 경우 사진이 Google의 Gemini API로 전송됩니다. 그 처리에는 Google의 약관과 개인정보 처리 조건이 적용되며, 이용 중인 키의 요금제에 따라 달라질 수 있으므로 Google의 현재 안내를 확인하세요. 개인 정보나 타인의 사진은 입력하지 않는 것이 좋습니다. 자세한 내용은 개인정보처리방침에 있습니다.

이 글에서 기억할 내용

  • 키는 Google AI Studio에서 직접 발급해 화면 위쪽 "API 키 설정"에 붙여 넣고 저장한다.
  • "Gemini 연결됨"이 보이면 준비된 것이고, 오류는 메시지가 알려 주는 원인(키, 한도, 혼잡, 권한)을 순서대로 확인한다.
  • 키는 내 브라우저에만 저장되므로 공용 컴퓨터에서는 쓰지 않거나 사용 후 지운다.
  • 키와 한도·요금 조건은 Google이 정하며 바뀔 수 있어 AI Studio의 현재 안내를 확인한다.
