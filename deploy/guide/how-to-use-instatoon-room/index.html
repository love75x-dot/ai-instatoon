인스타툰 연재실 사용법: 업종 입력부터 게시용 글까지 한 편 만들기

인스타툰 연재실은 가게 이야기를 4~10컷 인스타툰의 대본, 그림 프롬프트, 게시물 글로 정리해 주는 도구입니다. 그림 자체를 대신 그려 주지는 않습니다. 어디까지가 도구의 일이고 어디부터가 내 일인지 먼저 알면 첫 한 편이 훨씬 빨라져요.

작성일 2026-10-01 · 최종 업데이트 2026-10-01

이 글의 순서
  1. 먼저 알아둘 것: 도구가 하는 일과 내가 하는 일
  2. 1단계: 가게 이야기 적기
  3. 2단계: 대본 다듬기
  4. 3단계: 그림 만들기·저장·올리기
  5. 저장과 백업: 내 작업은 어디에 있나
  6. 처음 쓰는 사람을 위한 점검 순서

먼저 알아둘 것: 도구가 하는 일과 내가 하는 일

단계도구가 하는 일내가 하는 일
대본입력한 내용으로 컷별 구도, 제목, 대사, 말풍선 위치, 캡션, 해시태그 초안 생성이야기가 실제와 맞는지 읽고 고치기
그림캐릭터 시트용 프롬프트와 컷별 프롬프트를 순서대로 정리프롬프트를 ChatGPT 등에 붙여 넣어 그림을 받고, 컷마다 비교·선택
정리완성 그림을 정한 비율로 맞춰 PNG로 묶어 저장(zip), 캡션·해시태그 복사인스타그램에 직접 올리기

이 구조는 두 가지를 뜻합니다. 첫째, 대본과 글을 만들려면 Gemini API 키가 필요합니다(키 넣는 방법과 오류 해결 참고). 둘째, 그림의 품질과 캐릭터 일관성은 사용하는 외부 이미지 도구에 달려 있어 사람이 컷마다 확인해야 합니다.

1단계: 가게 이야기 적기

꼭 필요한 입력은 업종 하나입니다. 칩에서 고르거나 직접 입력할 수 있고, 나머지는 선택입니다. 다만 아래를 적을수록 대본이 일반적인 홍보 문구에서 벗어납니다.

  • 있었던 일: 질문 버튼에 맞춰 짧게 적어도 됩니다(언제, 누가, 무슨 일이 있었는지)
  • 주인공: 역할(사장님, 직원, 알바생 등), 성별, 나이, 외모 한 줄. 최대 3명까지 추가 가능
  • 컷 수와 비율: 4~10컷, 1:1·4:5·3:4 중 선택
  • 가게 프로필: 말투, 쓰면 안 되는 말, 항상 넣을 해시태그, 예약·문의 안내를 한 번만 적어 두면 이후 모든 편에 적용
예시 · 가상의 입력 예(분식집)

업종: 분식 / 가게 이름: 오늘도 떡볶이 / 있었던 일: 마감 직전에 온 손님이 "국물이 아까랑 다르네요"라고 해서 당황했는데 사실은 새로 끓인 것이었다 / 알리고 싶은 것: 국물은 시간대마다 새로 끓인다

주의

사진으로 외모 설명을 채울 수 있는 기능이 있지만, 사진은 본인이 동의한 경우에만 사용하세요. 사진은 캐릭터 설명을 만들 때 AI 서비스로 전송됩니다.

2단계: 대본 다듬기

"인스타툰 만들기"를 누르면 제목 후보, 컷별 대본, 게시물 캡션, 해시태그, 릴스용 글이 만들어집니다. 이 결과는 초안입니다. 컷 카드에서 제목, 대사, 구도 등을 직접 고칠 수 있고, 컷별 자동 점검 배지가 제목 길이, 대사 길이, 첫 장이 광고처럼 보이는지 등을 알려 줍니다.

그림을 그리기 전에는 "그림 그리기 전에 확인" 목록을 보세요. 대본에 들어간 가격·날짜·시간 같은 숫자, 과장 광고로 보일 수 있는 표현, 사진 사용 동의 여부가 모여 있고, AI 맞춤법 검사도 있습니다. 목록은 보조 수단이며 최종 확인은 사람이 해야 합니다. 자세한 항목은 AI 인스타툰 확인 목록에 있습니다.

3단계: 그림 만들기·저장·올리기

  1. 캐릭터 시트 프롬프트를 처음 한 번 외부 이미지 도구에 보내 기준 이미지를 만든다.
  2. 규칙 안내 문장을 보낸 뒤, 컷 프롬프트를 한 메시지에 한 컷씩 보낸다.
  3. 받은 그림을 파일 이름 순서대로 한꺼번에 올린다. 순서 바꾸기와 빼기가 가능하다.
  4. 비율 맞추기 방식(꽉 채우기/전체 보이기)을 고르고 zip으로 저장한다.
  5. 캡션과 해시태그를 복사해 인스타그램에서 직접 게시한다.
실전 팁

캐릭터가 컷마다 달라지면 캐릭터 일관성 가이드의 설정표 방식으로 설명을 더 단순하게 줄여 보세요.

저장과 백업: 내 작업은 어디에 있나

작성 내용, 사진, 기준 이미지, 완성 그림은 사용하는 브라우저의 저장 공간에 보관되며 운영 서버에 올라가지 않습니다. 그래서 브라우저 데이터를 지우거나 다른 기기를 쓰면 보이지 않을 수 있어요. 화면 위쪽의 "백업 저장"으로 JSON 파일을 받아 두고 "불러오기"로 복원하세요. 그림이 많으면 브라우저 저장 용량이 부족해질 수 있으니 작업을 마칠 때마다 백업과 zip 저장을 하세요.

저장되는 항목과 외부로 전송되는 정보는 개인정보처리방침에 자세히 적었습니다.

처음 쓰는 사람을 위한 점검 순서

  • Gemini API 키를 넣고 "Gemini 연결됨"이 보이는가
  • 업종을 골랐는가(이것만 있어도 대본은 만들어진다)
  • 대본의 가격·시간·상호명을 실제와 맞춰 봤는가
  • 사진을 쓴다면 본인 동의를 받았는가
  • 그림을 받은 뒤 컷 순서와 캐릭터 일관성을 확인했는가
  • 백업 저장을 했는가

화면 위쪽의 "예시 가게로 먼저 체험해 보기"로 샘플 가게의 대본과 연재표를 먼저 볼 수 있습니다. 체험이 끝나면 원래 작업으로 돌아갑니다.

이 글에서 기억할 내용

  • 필수 입력은 업종 하나이고, 이야기·주인공·가게 프로필은 적을수록 대본이 우리 가게답게 나온다.
  • 글(대본, 캡션, 해시태그)은 Gemini가 만들고, 그림은 사용자가 ChatGPT 같은 외부 이미지 도구에 프롬프트를 붙여 넣어 만든다.
  • 가격·시간 같은 숫자와 과장 표현은 "그림 그리기 전에 확인"에서 한 번 더 사람이 확인한다.
  • 작업 내용은 내 브라우저에만 저장되므로 백업 저장으로 파일을 받아 두는 것이 안전하다.
