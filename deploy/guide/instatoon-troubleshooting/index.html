인스타툰 만들다 막힐 때: 증상별 원인과 해결 방법

인스타툰을 만들다 보면 같은 자리에서 막히는 일이 자주 생깁니다. 캐릭터 얼굴이 바뀌고, 글자가 깨지고, 만들어 둔 것이 보이지 않는 식이에요. 이 글은 막히는 상황마다 증상 → 원인 → 해결 방법 순서로 정리했습니다. 지금 겪는 증상만 찾아서 읽으면 되고, "AI에게 보낼 문장"은 복사해서 그대로 붙여 넣으면 됩니다.

작성일 2026-10-06 · 최종 업데이트 2026-10-06

이 글의 순서
  1. 그림이 이상하게 나올 때
  2. 대본이 안 만들어지거나 마음에 들지 않을 때
  3. 작업이 사라지거나 저장·백업이 안 될 때
  4. 인스타그램에 올릴 때 막힐 때
  5. 그래도 안 풀릴 때 확인할 순서

그림이 이상하게 나올 때

그림은 사용자가 외부 이미지 AI(ChatGPT, Gemini 등)에 프롬프트를 붙여 넣어 받습니다. 이 단계에서 생기는 문제는 대부분 대화가 길어지면서 AI가 처음 받은 지시를 흐리게 기억해서 생겨요. 아래 문장은 한 메시지에 한 컷씩 보낼 때 가장 잘 먹힙니다.

캐릭터 얼굴·머리·옷이 컷마다 달라져요

증상: 1컷의 주인공과 4컷의 주인공이 다른 사람처럼 보입니다.

원인: 대화가 길어지면 AI가 처음 첨부한 캐릭터 이미지를 흐리게 기억합니다. 캐릭터 이미지를 첨부하지 않았을 때도 같은 일이 생겨요.

  1. 아래 문장을 보내서 그 컷만 다시 그리게 합니다. 한 메시지에는 한 컷만 보내야 덜 흔들려요.
  2. 그래도 계속 달라지면 새 대화창을 열고 "규칙 알려주기"부터 다시 합니다. 이때 캐릭터 이미지와 잘 나온 1컷을 같이 첨부하세요.
  3. 파일 버전을 쓴다면 "주인공 기준 이미지"가 마음에 드는지 먼저 확인하세요. 모든 컷이 그 얼굴을 따라갑니다.
예시 · AI에게 보낼 문장

캐릭터가 달라졌어요. 처음 첨부한 이미지와 얼굴, 머리 모양, 옷이 똑같도록 이 컷을 다시 그려 주세요. 장면과 구도는 그대로예요.

캐릭터 설명을 단순하게 줄이는 방법은 캐릭터 일관성 가이드에 더 자세히 있습니다.

한글 글자가 틀리거나 깨져서 나와요

증상: 말풍선이나 제목의 글자가 한두 글자 틀리거나 알아볼 수 없는 모양으로 나옵니다.

원인: 이미지 AI는 긴 문장과 받침이 많은 글자에 약합니다.

  1. 아래 문장을 보내 글자만 다시 넣게 합니다.
  2. "대본 다듬기"에서 한 줄을 12자 이하로 줄이면 훨씬 덜 틀립니다.
  3. 그래도 한두 글자가 틀리면 같은 대화창에서 그 컷만 다시 그리게 하는 것이 가장 빠릅니다.
예시 · AI에게 보낼 문장

글자가 틀리게 들어갔어요. 이번 컷에 드린 문구를 따옴표 안 글자 그대로, 한 글자도 바꾸지 말고 다시 넣어 주세요. 그림은 그대로 유지해 주세요.

그림 비율이 컷마다 다르거나 이상해요

증상: 어떤 컷은 정사각형, 어떤 컷은 세로로 길게 나옵니다.

원인: 이미지 AI가 가끔 요청한 비율을 무시하고 그립니다.

  1. 그냥 올려도 괜찮습니다. 올리는 순간 정해 둔 비율로 맞춰서 저장돼요.
  2. 가장자리가 잘리는 게 싫으면 "전체 보이기", 여백이 싫으면 "꽉 채우기"를 고릅니다.
  3. 다시 그리게 하고 싶으면 아래 문장을 보냅니다. 괄호 안의 비율은 내가 고른 비율로 바꿔 쓰세요.
예시 · AI에게 보낼 문장

비율이 앞 컷과 달라요. 그림 내용은 그대로 두고 (고른 비율, 예: 4:5 세로 비율 1080×1350px)로 다시 그려 주세요.

글자 모양이 1컷과 달라요

증상: 2컷부터 글씨체나 크기가 1컷과 다르게 나옵니다.

원인: 컷마다 새로 그리다 보니 글씨체와 크기가 조금씩 바뀝니다. 글자 모양은 고른 테마에 맞게 모든 컷 프롬프트에 똑같이 들어가 있어요.

  1. 아래 문장과 함께 완성된 1컷 그림을 첨부해서 보냅니다.
예시 · AI에게 보낼 문장

글자 모양이 1컷과 달라요. 1컷과 같은 글씨체, 같은 크기, 같은 위치, 같은 외곽선으로 이 컷의 글자를 다시 넣어 주세요.

이름표·영어·지어낸 간판 글자가 그림에 들어가요

증상: 인물 옆에 "대표, 30대" 같은 글자가 붙거나, 간판·메뉴판·휴대폰 화면에 내가 적지 않은 글자가 생깁니다.

원인: AI가 캐릭터 설명(예: "프리랜서, 30대")을 글자로 그려 넣거나, 비어 있는 간판과 화면을 채우려고 글자를 지어냅니다.

  1. 아래 문장을 보내 글자를 빼고 다시 그리게 합니다.
  2. 브랜드 이름이나 상품명을 그림에 꼭 넣고 싶으면 대본의 제목·대사·자막 칸에 적어 주세요. 그 글자만 들어갑니다.
예시 · AI에게 보낼 문장

그림에 제가 드리지 않은 글자가 들어갔어요. 인물 옆 이름·나이·역할 글자, 영어, 간판·메뉴판·화면 속 지어낸 글자를 모두 지우고, 제가 따옴표로 드린 문구만 남긴 같은 장면으로 다시 그려 주세요.

글자를 아예 빼고 싶을 때는 아래 문장을 쓰세요.

예시 · AI에게 보낼 문장

그림에 글자가 들어갔어요. 글자, 숫자, 말풍선을 모두 빼고 같은 장면으로 다시 그려 주세요.

AI가 그림은 안 그리고 글로만 답해요

증상: 프롬프트를 보냈는데 그림 없이 장면 설명만 돌아옵니다.

원인: 그림을 못 그리는 모델을 쓰고 있거나, 요청을 설명하라는 뜻으로 알아들었을 때 그렇습니다. 실제 브랜드·유명인·특정 작품 캐릭터를 요청하면 거절하기도 해요.

  1. 아래 문장을 보내 봅니다.
  2. Gemini는 이미지 만들기가 되는 모드인지, ChatGPT는 이미지 생성이 되는 요금제·모델인지 확인하세요.
  3. 거절당했다면 그림 설명에서 실제 상표·인물·작품 이름을 빼고 다시 보냅니다.
예시 · AI에게 보낼 문장

설명 말고 이미지로 그려 주세요. 방금 드린 장면을 (고른 비율) 그림 한 장으로 만들어 주세요.

대본이 안 만들어지거나 마음에 들지 않을 때

"인스타툰 만들기"를 눌러도 안 되거나 오류가 떠요

증상: 버튼이 눌리지 않거나, 누르면 오류 안내가 뜹니다.

원인: 분야가 비어 있거나 AI 연결이 안 된 경우가 대부분입니다.

  1. 분야(업종)가 선택돼 있는지 확인하세요. 꼭 필요한 입력은 분야 하나입니다.
  2. 화면 오른쪽 위에 초록 점과 "AI 연결됨"(파일 버전은 "Gemini 연결됨")이 보이는지 확인하세요. 안 보이면 API 키를 다시 넣어 주세요. 방법은 Gemini API 키 넣는 방법과 오류 해결에 있습니다.
  3. 처음 누를 때 뜨는 허용 창에서는 허용을 눌러야 합니다.
  4. 잠깐 생긴 문제라면 1분 뒤 다시 누르세요. AI 없이 "직접 쓰기"로 만들 수도 있어요.

대본이 밋밋하고 재미없어요

증상: 어디서 본 듯한 일반적인 이야기로 나옵니다.

원인: "있었던 일" 칸이 비어 있으면 AI가 흔한 이야기로 채웁니다.

  1. "있었던 일" 칸 위의 질문 버튼에 답해 보세요. 시간, 장소, 상대방이 한 말 한마디만 있어도 대본이 확 달라집니다.
  2. "더 자세히 설정하기"에서 분위기를 바꿔 봅니다.
  3. 컷마다 "제목 아이디어 5개", "이 컷 고치기"(예: 더 반전 있게), "고객 눈으로 점검받기"를 써 보세요.
예시 · 가상의 예(1인 사업)

밋밋한 입력: "새 상품이 나왔어요" / 살아나는 입력: "지난 금요일 밤 9시, 첫 주문 고객이 '포장이 너무 예뻐서 선물받은 줄 알았어요'라고 보내 줬어요"

작업이 사라지거나 저장·백업이 안 될 때

만들어 둔 게 사라졌어요

증상: 어제까지 있던 작업이 보이지 않고 처음 화면이 나옵니다.

원인: 작업 내용은 이 브라우저에만 저장됩니다. 다른 컴퓨터, 다른 브라우저, 시크릿 창에서 열었거나 인터넷 사용 기록을 지우면 보이지 않아요.

  1. 평소 쓰던 컴퓨터와 브라우저에서 다시 열어 보세요.
  2. 백업 파일이 있다면 화면 오른쪽 위 "불러오기"로 그 파일을 고르면 그대로 돌아옵니다.
  3. 앞으로는 한 편을 끝낼 때마다 "백업 저장"을 눌러 두세요.

"브라우저 저장 공간이 가득 찼다"는 안내가 떠요

증상: 저장 공간이 가득 차서 새로고침하면 작업이 사라질 수 있다는 안내가 나옵니다.

원인: 그림과 사진이 많으면 브라우저가 허용하는 저장 용량을 넘을 수 있습니다.

  1. 지금 바로 "백업 저장"으로 파일을 받아 두세요.
  2. 완성한 그림은 zip으로 저장해 컴퓨터에 보관하세요.
  3. 새로고침이나 탭 닫기는 백업을 받은 뒤에 하세요.
주의

저장 공간 안내가 떴을 때 새로고침하면 아직 백업하지 않은 작업이 사라질 수 있습니다. 백업 파일을 먼저 받으세요.

저장 버튼을 눌러도 파일이 안 받아져요

증상: zip이나 이미지 저장 버튼을 눌러도 다운로드가 시작되지 않습니다.

원인: 브라우저가 다운로드를 막았거나 확인 창을 닫은 경우입니다.

  1. 저장할 때 뜨는 확인 창에서 허용·저장을 눌러 주세요.
  2. 그래도 안 되면 완성 이미지를 마우스 오른쪽 버튼(휴대폰은 길게 눌러서)으로 눌러 저장하세요.

백업 파일을 불러오려는데 "백업 파일이 아니에요"라고 나와요

증상: "인스타툰 연재실 백업 파일이 아니에요. 백업 저장으로 받은 .json 파일을 골라 주세요"라는 안내가 뜹니다.

원인: 백업 저장으로 받은 .json 파일이 아닌 다른 파일(이미지, zip, 다른 프로그램의 json)을 골랐을 가능성이 큽니다.

  1. 파일 이름이 "인스타툰_백업_….json" 형태인지 확인하세요.
  2. 다운로드 폴더에서 같은 이름의 최신 파일을 다시 골라 보세요.
  3. 파일을 직접 열어 수정했다면 원본 파일로 다시 시도하세요.

인스타그램에 올릴 때 막힐 때

인스타에 올렸더니 그림 가장자리가 잘려요

증상: 올린 게시물에서 컷의 가장자리가 잘려 보입니다.

원인: 인스타그램은 사진을 고를 때 기본으로 정사각형으로 자릅니다. 한 게시물에 올린 모든 장은 첫 장의 비율을 따라가요.

  1. 사진 고르는 화면에서 비율(확장) 버튼을 눌러 원본 비율로 바꾼 뒤 여러 장을 선택하세요.
  2. 이 사이트에서 저장한 이미지는 모든 컷이 같은 비율이라 첫 장만 맞추면 나머지도 맞습니다.
실전 팁

올리기 전에 휴대폰 미리보기에서 첫 장과 마지막 장의 글자가 잘리지 않았는지 한 번 더 확인하세요. 게시 전 점검 항목은 AI 인스타툰 확인 목록에 있습니다.

그래도 안 풀릴 때 확인할 순서

위에서 증상을 찾지 못했거나 해결되지 않으면 아래 순서대로 시도해 보세요. 앞 단계에서 풀리면 뒤 단계는 하지 않아도 됩니다.

순서할 일이유
1"백업 저장"으로 파일을 먼저 받아 둔다이후 새로고침이나 다른 조치를 해도 작업을 잃지 않기 위해
2페이지를 새로고침한다일시적인 화면 오류는 대부분 이것으로 풀린다
3이미지 AI에서는 새 대화창을 열고 규칙부터 다시 보낸다긴 대화에서 흐려진 지시를 초기화한다
4다른 브라우저나 기기에서 "불러오기"로 백업을 열어 본다브라우저 문제인지 작업 내용 문제인지 구분한다
  • 백업 저장 파일을 받아 두었는가
  • 분야가 선택돼 있고 AI 연결 표시가 보이는가
  • 이미지 AI에는 한 메시지에 한 컷만 보냈는가
  • 캐릭터 이미지와 잘 나온 1컷을 함께 첨부했는가

도구를 처음 쓴다면 인스타툰 연재실 사용법에서 전체 흐름을 먼저 확인해 보세요.

이 글에서 기억할 내용

  • 그림 문제(캐릭터 변화, 글자 깨짐, 비율, 지어낸 글자)는 대부분 AI가 앞의 지시를 흐리게 기억해서 생기고, 한 메시지에 한 컷만 보내면 줄어든다.
  • "만들기" 버튼이 안 될 때는 분야 선택 여부와 AI 연결 상태를 먼저 확인한다.
  • 작업 내용은 내 브라우저에만 저장되므로 한 편이 끝날 때마다 백업 저장으로 파일을 받아 둔다.
  • 인스타그램에 올릴 때 가장자리가 잘리면 사진 선택 화면에서 원본 비율로 바꾼 뒤 여러 장을 고른다.
