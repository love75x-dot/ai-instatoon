# 인스타툰 연재실 리뉴얼 계획 (RENEWAL_PLAN)

> 작성: 2026-10-13 · 운영 주소: https://www.ai-instatoon.com (Cloudflare Workers)
> 이 문서는 리뉴얼 작업의 기준 문서예요. 작업할 때마다 이 문서를 먼저 읽고, 바뀐 결정은 맨 아래 "결정 기록"에 추가해 주세요.

---

## 0. 이용자 피드백 (리뉴얼 이유)

1. 눌러야 할 버튼이 너무 많다.
2. 전체적으로 귀여운(귀욤귀욤) 스타일이라, 모던하고 심플했으면 좋겠다.
3. 첫 화면 오른쪽 위 "콘텐츠 가이드"는 원래 블로그 게시판으로 만든 건데, 이름 때문에 설명서처럼 느껴진다.

## 개선 방향

"기능을 더 붙이기보다, 모바일에서의 마찰과 밀도를 줄이고 그림 프롬프트 품질은 그대로 지킨다."
기능은 이미 풍부하다. 문제는 길이, 안내문 반복, 글자 겹침, 수동 복붙이다.

## 절대 지킬 것 (모든 작업의 전제)

1. **프롬프트 품질 보호**
   - 3단계에서 나오는 컷별·규칙·안내 카드 프롬프트 문장은 바꾸지 않는다.
   - 현재 프롬프트를 예시 데이터(예시 가게 "보리당" 등)로 뽑아 **골든 파일**로 저장하고, UI를 바꿀 때마다 자동으로 비교한다.
   - 문장이 바뀌어야 하면 이유를 먼저 보고하고 승인받는다.
   - 칸을 줄이더라도 효과음·자막·작은 글씨·말풍선 종류·노란 강조 같은 기존 결과물 요소는 프롬프트에 그대로 남긴다.
2. **기존 데이터 호환**
   - 이용자 브라우저 저장 작업(localStorage)과 기존 백업 파일이 리뉴얼 후에도 그대로 불러와져야 한다.
   - 이것도 자동 검사로 만든다.
3. **주소 유지 (검색 노출 보호)**
   - `/guide/` 글 주소, sitemap, canonical은 바꾸지 않는다. (구글 서치콘솔·네이버 서치어드바이저 등록 완료 또는 진행 중)
   - 꼭 바꿔야 하면 301 리디렉트를 건다.
4. **진행 방식**
   - 단계마다 새 브랜치 → 미리보기 주소에서 사장님 확인 → "병합"이라고 하면 main에 합친다.
   - main에 바로 올리지 않는다.
   - 확실하지 않은 내용은 "확인 필요"로 표시한다.

## 결정 사항

### 1. 퀄리티 보호
- 위 "절대 지킬 것" 1·2번과 같음.

### 2. 첫 화면과 API 키
- API 키는 시작 전이 아니라 "만들기"를 누를 때 **바닥 시트**로 받는다.
- 연결되면 접고 "연결됨 ✓"만 보인다. 키 테스트 버튼을 넣는다.
- "무료 키는 입력 내용이 Google 개선에 쓰일 수 있어요" 안내를 넣는다.
- 체험 모드에서는 "API 키 필요" 표시를 숨기거나 바꾼다.
- 입력칸 아래에 "저장은 이 브라우저에만, AI 호출은 내 Google 키로" 안내를 넣는다.
- 하단에 FAQ 5개와 결과 갤러리 자리를 만든다.

### 3. 인스타그램 미리보기
- 1단계 미리보기는 없앤다.
- 2단계 상단에 **텍스트 스토리보드**(컷 번호·역할·상황·대사, 그림 박스 없음)를 둔다.
- 2단계 하단에 **캡션 미리보기**(글자 수, 첫 125자 기준선)를 둔다.
- 인스타 카드 형태의 미리보기는 3단계에서 그림을 올린 뒤에만 보인다.

### 4. 컷 편집 (2단계)
- 기본 칸은 4개: **등장인물(신규), 대사, 그림 설명, 화면 구도**.
- 나머지 칸은 "값이 있으면 항상 보이고, 빈 칸만 '+ 추가' 뒤에" 둔다. 접어도 값은 한 줄 요약 칩으로 보인다.
- 대사는 **[인물][종류][대사]** 입력 줄(최대 3줄).
- 노란 강조는 단어를 눌러 지정한다.
- 디테일은 추천 칩 + 직접 입력.
- 효과음·작은 글씨·자막 박스는 **화면에서만 합치고**, 데이터와 프롬프트는 종류별로 유지한다.
- 신규 항목:
  - 표정·감정
  - 배경·시간대
  - 앞 컷과 같은 배경 유지
  - 이 컷에서 달라진 점
  - "이 컷 프롬프트 보기"
  - 대사 글자 수 경고
  - "확정 ✓" 토글
- "제외할 것" 프리셋은 기본 꺼짐.
- "AI에게 부탁하기"는 없애지 않고 접어 둔다. 직접 수정이 기본이고, 호출 범위는 해당 컷 위주로 줄인다.

### 3단계 (그림·저장)
- "다음 항목 복사" 버튼으로 프롬프트를 순서대로 복사한다.
- 복사한 항목은 ✓ 처리하고, 진행 표시(예: 3/8)를 보여 주고, 복사 상태를 저장한다.
- **젠스파크 전용 프롬프트** 추가 (별도 요청 내용 참고):
  - [공통 설정]과 [장별 내용]을 분리한 구조화 프롬프트
  - "젠스파크 전체 한 번에 복사", "6장씩 나눠 복사", 컷별 "젠스파크용 복사"
  - 안내: 모델은 GPT Image 또는 Nano Banana Pro 추천, 기준 이미지 첨부, 4:5 대신 3:4, 어색한 장만 다시 만들기, Edit Text로 글자 수정
  - 기존 GPT/Gemini용 순서와 버튼은 유지, 탭이나 접기로 구분

### 5. 디자인 시스템 (모던 심플, GenToon 비교 반영)
- 주 버튼은 **검정 알약 하나**로 통일한다(화면당 1개). 보조는 외곽선, 3순위는 텍스트 링크.
- 노랑은 버튼이 아니라 배지·형광펜·"지금 할 일" 칩에만 쓴다.
- 한글 줄바꿈은 `word-break: keep-all`로 해결한다. "내 이야기 적/기"처럼 단어 중간에서 꺾이는 문제를 없앤다.
- 폰트는 Pretendard Variable 같은 한글 UI 폰트에 대체 폰트를 둔다.
  - 본문 16px, 보조 13px 이상, 진한 회색(대비 4.5:1 이상)
- 입력칸 16px·높이 48px, 카드 모서리 16~20px, 키보드 포커스 표시.

### 6. 모바일과 PC 구분
- **모바일**
  - 하단 고정 주 버튼
  - 상단 한 줄 단계 칩
  - 스타일 갤러리 2열, 기본값 선택
  - 입력 아코디언
  - 안쪽 스크롤 제거
  - 뒤로가기가 이전 단계로 가는 URL 해시
  - 상단 버튼은 ⋯ 메뉴 + "도움말"로 통합
- **PC**
  - 2열 레이아웃(왼쪽 입력, 오른쪽 고정 패널)
  - 2단계 컷 목록 + 편집 칸 분할
  - 3단계 드래그앤드롭 업로드
  - 갤러리 4열
  - 호버 상태

### 7. 버그·정리
- "더 설정하기" 행의 제목·설명 겹침
- 회색 비활성처럼 보이는 "인스타툰 만들기" 버튼 → 항상 활성 + 필수칸 안내
- ①②③ 번호 혼재
- 탭의 "1-3/선택" 배지
- 긴 "지금 할 일" 배너
- 한 달 기획의 담당자 칸 → 팀 모드로
- 상태 칩, 파란 가이드 링크
- "방금 저장됨" 표시와 7일 백업 알림

### 8. 비용·신뢰 안내
- "AI 호출 안내" 카드: 직접 수정은 호출 없음, 비용은 내 Google 키로 청구
- 이번 편 호출 횟수 표시
- 푸터에 운영자·문의·업데이트 날짜
- 우하단 "문의·제보" 버튼(서버 없이 폼 링크)

### 9. 성능·공유
- 이미지 지연 로딩, WebP, 크기 지정
- 공유 이미지(og:image), 트위터 카드, 테마색 추가
- PWA(홈 화면 추가 + 저장 데이터 보호 요청)
- 본문 바로가기 링크
- 크롬 Lighthouse로 측정

### 10. "콘텐츠 가이드" → 블로그 게시판
- 주소 `/guide/`는 그대로 두고, **화면에 보이는 이름과 모양만** 블로그 게시판처럼 바꾼다.
- 메뉴 이름 후보→ **"인스타툰 노트"로 확정**(후보였던 블로그·사장님 노트는 채택 안 함)
- 글 목록: 최신순, 카테고리, 날짜, 대표 이미지가 있는 게시판 형태.
- 글 작성 흐름(`npm run guide:new`, check, sitemap 자동 생성)은 유지한다.
- 나중에 RSS(`rss.xml`) 추가 예정(블로그 본격 운영 시).

## 단계 계획 (2026-10-13 구체화 · 사장님 확인 완료)

표기: **리뉴얼 N단계**는 이 계획의 단계, **앱 N단계**는 화면 안의 1·2·3단계(입력·컷 편집·그림/저장)예요. 작업량: 소(반나절 안팎) · 중(하루 안팎) · 대(이틀 이상).
모든 단계 공통: 새 브랜치 → 미리보기 주소 확인 → "병합" 후 main. 단계마다 `npm run check`(골든·호환·주소 검사)를 통과해야 미리보기를 드림.

### 0단계 · 안전장치 — `renewal-0-safety` (작업량 중)
- 바뀌는 화면: 없음.
- 만드는 것: 프롬프트 골든(`dev/golden/`), 데이터 호환 검사(`dev/compat/`), 지금 화면 캡처와 주소·sitemap·canonical 기준(`dev/snapshots/`), 공통 도구(`dev/lib/`). 검사는 `playwright-core`로, 내 컴퓨터의 `npm run check`에서만 돈다(Cloudflare 빌드는 `npm run build`만 실행).
- 호환 검사 범위: 현재 형식 localStorage 전체, 옛 v3, 잔재 필드 v4, 백업 파일 불러오기→내보내기 왕복, IndexedDB 없는 브라우저. "저장소 이전" 단계용 조건(원본 보존)도 미리 넣어 둠.
- 위험: 시각·난수가 흔들리면 골든이 불안정 → 시계·난수 고정으로 해결. 미리보기 주소가 실제로 열리는지 이번에 처음 확인.
- 사장님 확인: 미리보기 주소가 열리고 사이트가 평소와 같은지, 골든 시나리오(16종)가 충분한지.

### 1단계-앱 · 디자인 시스템과 버그 정리 — `renewal-1-design` (작업량 대)
- 바뀌는 화면: 앱 전체(검정 알약 주 버튼, 노랑은 배지·형광펜만, Pretendard + `keep-all`, 입력칸 16px·48px, 카드 모서리, 포커스 표시). 버그: "더 설정하기" 겹침, 회색처럼 보이는 만들기 버튼, ①②③ 혼재, "1-3/선택" 배지, 긴 "지금 할 일" 배너, 상태 칩, 파란 가이드 링크.
- 한 달 기획·릴스·반응 분석 탭: 색·폰트·버튼만 새 디자인 적용, 구조는 그대로. 담당자 칸은 기본 숨김, 설정에서 "팀 모드"를 켜면 보임(기존 입력값 유지).
- 폰트: Pretendard를 CDN에서 필요한 글자만 받는 방식으로 추가하고 `privacy` 페이지에 한 줄 추가. Google Fonts 30여 개는 그림 글자 기능·골든에 영향이 없는지 확인한 뒤 제거.
- 죽은 코드: 화면 쪽만 정리. 불러오기에서 옛 필드를 읽는 코드는 남김.
- 위험: CSS 변경 범위가 넓음. 프롬프트는 안 건드리므로 골든이 100% 같아야 함.
- 사장님 확인: 모바일·PC 느낌, 버튼 수, 글자 겹침 없음.

### 1단계-게시판 · "인스타툰 노트" — `renewal-1b-board` (작업량 중)
- 바뀌는 화면: 허브(`/guide/`)가 최신순·카테고리·날짜·대표 이미지 카드의 게시판 형태로 바뀜. 메뉴 이름은 **"인스타툰 노트"**.
- 이름은 `<title>`, 화면 브레드크럼, 구조화 데이터(BreadcrumbList 등)까지 함께 맞춤. **주소(/guide/…), sitemap, canonical, robots는 그대로**(`dev/snapshots/seo.mjs`가 검사).
- 대표 이미지: 카테고리별 공통 이미지로 시작, 글마다 따로 지정 가능(글 파일에 선택 항목).
- 유지: `npm run guide:new`·check·sitemap 자동 생성, `data-track` 추적 속성. `verify.mjs`의 이름 검사는 새 이름에 맞게 수정.
- 사장님 확인: 목록 모양, 카테고리 이미지, 글 페이지 이름 표기.

### 2단계 · 첫 화면, API 키 바닥 시트, 미리보기 정리 — `renewal-2-start` (작업량 대)
- 바뀌는 화면: 키 입력이 "만들기" 시점의 바닥 시트로(연결되면 "연결됨 ✓", 키 테스트 버튼), 안내 문구, 체험 모드 표시, FAQ 5개와 갤러리 자리, 앱 1단계 폰 미리보기 삭제. 모바일: 상단 한 줄 단계 칩, 하단 고정 주 버튼, 입력 아코디언, 스타일 갤러리 2열, 뒤로가기용 URL 해시, 상단 버튼은 ⋯ 메뉴 + "도움말".
- PC 오른쪽 패널: 앱 1단계는 **요약 카드**(가게·테마·인물·컷 수·지금 할 일), 앱 2단계는 **텍스트 스토리보드**.
- "무료 키는 입력 내용이 Google 개선에 쓰일 수 있어요" 문구는 Gemini API 공식 약관에서 확인한 문장만 사용하고 출처 링크를 보고. 확인이 안 되면 넣지 않음.
- 새 기능은 사이트용으로만. 아티팩트 모드 코드는 지우지 않고 깨지지 않을 정도로만 유지.
- **같이 고칠 것:** 첫 방문 둘러보기(`startTour`)가 앱 작업 단계를 1단계로 되돌리는 문제(`instatoon.helpSeen`이 없을 때, 복원한 작업이 있어도 1단계로 이동). 기존 작업이 있으면 단계를 건드리지 않게 수정하고, 검사에서 `helpSeen` 없이도 단계가 유지되는지 확인.
- 위험: API 키는 `instatoon.key` 그대로 저장해야 호환. 해시 이동과 앱 단계 상태가 어긋나지 않게.
- 사장님 확인: 키 없음/있음 흐름, 체험 모드, 모바일 하단 버튼이 키보드를 가리지 않는지.

### 2.5단계 · 저장소 이전 (IndexedDB) — `renewal-2b-storage` (작업량 대)
- 바뀌는 화면: 거의 없음(저장 실패 안내와 "방금 저장됨" 정도).
- 조건: ① 처음 열 때 기존 localStorage 데이터를 자동으로 옮기고, **옮긴 게 확인되기 전에는 원본을 지우지 않음**(확인 후 `instatoon.storage.verified=1` 표시) ② 기존 백업 파일 내보내기·불러오기 형식(v1) 그대로 호환 ③ IndexedDB를 못 쓰는 브라우저는 localStorage로 동작.
- 대상: `instatoonRoom.v4`, 사진·기준 이미지·샘플, `instatoon.copied`, 설정 키 전체(코드에서 뽑은 키 기준, 관리자 키 `instatoon.admin.*` 포함). 옛 폰트 DB(`instatoonFonts`)는 그대로.
- 위험: 가장 데이터 위험이 큰 단계. 이전 도중 탭이 닫히는 경우, 두 탭이 동시에 열린 경우, 용량 초과를 검사에 넣음.
- 사장님 확인: 기존 작업이 있는 브라우저에서 열어 그대로 보이는지(백업 파일을 먼저 받아 둘 것).

### 3단계 · 앱 2단계(컷 편집) 개편 — `renewal-3-edit` (작업량 대)
- 바뀌는 화면: 기본 4칸(등장인물·대사·그림 설명·화면 구도), 나머지는 "+ 추가"와 한 줄 요약 칩, [인물][종류][대사] 줄 입력(최대 3줄, 저장은 기존 `"인물: 대사"` 문자열 형식 그대로), 단어 눌러 노란 강조, 디테일 추천 칩, 컷 확정 토글, "이 컷 프롬프트 보기", 글자 수 경고. 새 항목: 표정·감정, 배경·시간대, 앞 컷과 같은 배경 유지, 이 컷에서 달라진 점.
- **프롬프트 규칙:** 새 항목이 비어 있으면 프롬프트가 한 글자도 안 바뀌고(골든 일치), 채웠을 때만 문장이 추가됨. 추가 문장은 이 단계에서 보고하고 승인받은 뒤 새 골든으로 저장.
- 효과음·작은 글씨·자막 박스는 화면에서만 합치고 데이터·프롬프트는 종류별 유지. "AI에게 부탁하기"는 접어 두되 유지.
- 위험: 노란 강조가 문자열 하나(`highlight`)라 같은 단어가 두 번 나올 때 처리 방식 필요. 새 필드는 모두 "없어도 되는" 추가 필드로.
- 사장님 확인: 같은 입력의 프롬프트가 이전과 같은지(골든), 옛 작업을 불러왔을 때 컷 내용이 그대로인지, 추가 문장 승인.

### 4단계 · 앱 3단계 "다음 항목 복사", 젠스파크, 모바일·PC 구분 — `renewal-4-copy` (작업량 대)
- 바뀌는 화면: 순서대로 복사 버튼, 진행 표시(3/8), 복사 상태 저장(`instatoon.copied` 이어서 사용), **젠스파크용 탭**(아래 부록 요청서), PC 2열·드래그앤드롭·갤러리 4열.
- 기존 GPT/Gemini용 순서와 버튼은 그대로. 기존 골든 불변, 젠스파크 프롬프트는 새 골든 파일로 따로 저장(보리당 예시로 미리보기).
- 사장님 확인: 복사 순서, 새로고침 후 ✓ 유지, 젠스파크에 실제로 붙여 넣어 결과가 나오는지.

### 5단계 · 비용·신뢰 안내, 성능·공유 — `renewal-5-trust` (작업량 중)
- 바뀌는 화면: AI 호출 안내 카드, 이번 편 호출 횟수, 푸터(운영자·문의·업데이트 날짜), 우하단 문의·제보 버튼, og:image·트위터 카드·테마색, 본문 바로가기, PWA(**매니페스트와 저장 보호 요청까지만, 서비스 워커 없음**), 이미지 지연 로딩·WebP.
- 운영자 이름과 문의 폼 링크는 사장님이 나중에 전달 → 이번에는 **빈 자리**로 만들어 둠.
- 위험: 샘플 그림(640KB)을 WebP 파일로 빼면 "한 파일 앱" 구조가 바뀜(`build.mjs`, 파일 버전 `instatoon.html`에 영향).
- 사장님 확인: Lighthouse 전·후, 공유 미리보기, 빈 자리 위치.

## 확인 결과 기록
- `ADM_PW`(`instatoon.admin.pw`): 로컬 관리자 화면(프롬프트·테마 편집, `#admin` 해시)의 비밀번호 잠금에서 **지금도 사용 중**. 그대로 두고 읽기·쓰기 모두 유지.
- 저장 키 중 문서에 없던 것: `instatoon.copied`, `instatoon.admin.arts/prompts/manual/pw`(+세션 `instatoon.admin.ok`). 호환 검사는 코드에서 뽑은 키 전체를 기준으로 함.
- 첫 방문(`instatoon.helpSeen` 없음)이면 둘러보기가 앱 단계를 1단계로 되돌림 → **2단계에서 수정 예정**. 그때까지 검사는 기존 이용자처럼 `helpSeen=1`을 깔고 실행.
- `npm install`이 만드는 `package-lock.json`은 저장소에 원래 없었음. Cloudflare 빌드 동작을 바꾸지 않으려고 커밋하지 않음.

## 부록: 젠스파크 전용 프롬프트 요청서 (4단계에서 사용)

앱 3단계에 "젠스파크용" 탭(또는 접기)을 추가한다. 기존 GPT/Gemini용 순서와 버튼은 그대로 유지한다.
- 프롬프트 구조:
  - [작업] 아래 내용으로 인스타툰 N장을 순서대로, 한 장씩 따로 만들어 주세요.
  - [공통 설정] 비율 3:4, 그림 스타일/테마, 등장인물 설명(기준 이미지 첨부 안내), 장별 등장인물, 공통 배경, 글자 규칙 요약(말풍선, 효과음, 노란 강조, 자막)
  - [장별 내용] 1장~N장: 장면, 구도, 인물 표정, 대사와 글자 위치
  - [마무리] 인물 얼굴과 옷이 모든 장에서 같게, 글자는 한글 그대로 정확히
- 버튼: "젠스파크 전체 한 번에 복사", "6장씩 나눠 복사", 컷별 "젠스파크용 복사"

- 기존 골든 프롬프트는 바뀌면 안 된다. 젠스파크용 프롬프트는 새 골든 파일로 따로 저장한다.
- 미리보기는 "보리당" 예시로 보여 준다.
