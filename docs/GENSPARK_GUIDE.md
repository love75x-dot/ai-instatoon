# 젠스파크 AI 이미지 · 웹툰 캐릭터 일관성 가이드

> 젠스파크 **AI 이미지(AI Image)** 기능 기준으로 정리한 프롬프트·지침 모음입니다.
> 프롬프트 자체는 레퍼런스 이미지를 지원하는 다른 모델(Nano Banana, Seedream 등)에서도 그대로 쓸 수 있습니다.

---

## 0. 젠스파크 기본 설정 (시작 전 체크)

| 항목 | 권장 설정 | 이유 |
|---|---|---|
| 모델 | **Nano Banana Pro** 직접 선택 (자동 선택 X) | 레퍼런스 유지력이 가장 좋음. 자동 선택은 컷마다 모델이 바뀌어 그림체가 흔들릴 수 있음 |
| 대안 모델 | Nano Banana 2 (빠르고 저렴) / Seedream (그림체가 밋밋할 때) | |
| 텍스트 들어간 이미지 | GPT Image / Ideogram | 표지·타이틀·간판 글자용. 캐릭터 컷에는 쓰지 않기 |
| 참조 이미지 | 최대 **14장**까지 업로드 가능 | 캐릭터당 2~3장 × 인원수로 배분 |
| 비율 | 기준 이미지·표정 시트 **1:1**, 턴어라운드 **16:9**, 웹툰 컷 **9:16 또는 3:4** | |
| 수정 | 다시 뽑기보다 **편집 기능**(선택 영역 편집, 오브젝트 삭제, 배경 제거, 확장) 활용 | 맞은 부분은 지키고 틀린 부분만 고칠 수 있음 |

**핵심 원칙: 한 작품은 처음부터 끝까지 같은 모델로 작업한다.**

---

## 1. 전체 작업 순서

1. 공통 그림체 문장 확정 (작품당 1개)
2. 캐릭터 카드 작성 (캐릭터당 1개)
3. 기준 이미지 생성 → 1장 확정
4. 턴어라운드 시트 생성 (기준 이미지 첨부)
5. 표정 시트 생성 (기준 이미지 첨부)
6. (선택) 의상 바리에이션 시트 생성
7. 모든 파일을 이름 규칙대로 저장
8. 웹툰 컷 생성 시 매번 레퍼런스 첨부 + 문장 복붙

---

## 2. 공통 그림체 문장 (모든 캐릭터 · 모든 컷에 동일하게)

```
[그림체] 한국 웹툰 스타일, 깔끔한 디지털 셀 채색,
일정한 굵기의 검은 선화, 부드러운 2단 명암,
밝고 선명한 색감, 세로 스크롤 웹툰용 고해상도
```

- 작품 분위기에 맞게 한 번만 수정하고, 이후로는 **한 글자도 바꾸지 않기**
- 예) 로맨스: `파스텔 톤, 부드러운 빛 번짐` / 액션: `강한 명암 대비, 굵은 선화` / 일상: `채도 낮은 따뜻한 색감`

---

## 3. 캐릭터 카드 템플릿

```
[캐릭터 ID] 이름_영문자 (예: 하윤_A)
- 역할: (주인공 / 서브 / 조연)
- 나이/성별:
- 키/체형: (예: 168cm, 마른 체형, 긴 팔다리, 7.5등신)
- 얼굴형: (예: 갸름한 계란형, 뾰족한 턱)
- 눈: 모양 + 색 (예: 크고 살짝 처진 눈, 짙은 갈색 눈동자)
- 눈썹: (예: 얇고 일자)
- 코/입: (예: 작은 코, 얇은 입술)
- 피부톤: (예: 밝은 웜톤)
- 헤어: 색 + 길이 + 스타일 + 앞머리
  (예: 애쉬그레이, 어깨 단발, 끝이 바깥으로 뻗음, 눈썹 덮는 앞머리)
- 고유 특징: (예: 왼쪽 눈 밑 점, 둥근 은테 안경)
- 기본 의상: 상의 / 하의 / 신발 / 소품 + 색
  (예: 오버핏 머스타드 후드티, 검정 와이드 팬츠, 흰 운동화, 은색 실 반지)
- 대표 색상 팔레트: (예: 헤어 #A9B0B8 / 후드 #D4A017 / 눈 #4A2C1A)
- 기본 표정/분위기: (예: 무심한 듯 차분함)
- 절대 바뀌면 안 되는 것: (예: 점 위치, 안경, 헤어 색)
```

### 작성 요령
- 색은 "노란색"보다 **"머스타드 옐로"**처럼 구체적으로, 가능하면 HEX 코드도 함께
- **고유 특징 1~2개**는 반드시 넣기 (AI가 캐릭터를 구분하는 앵커 역할)
- "절대 바뀌면 안 되는 것" 줄을 컷 프롬프트에 그대로 옮기기

### 여러 명일 때 체크
- 헤어 색, 키, 체형, 실루엣이 **서로 확실히 다르게**
- 비슷한 색 의상 피하기 (컷 안에서 캐릭터가 섞이는 주원인)
- 캐릭터 ID는 짧고 겹치지 않게 (`하윤_A`, `도현_B`, `서진_C` …)

## 4. 기준 이미지 프롬프트 (레퍼런스 없이 처음 생성)

**비율 1:1 또는 3:4**

```
[공통 그림체 문장 붙여넣기]
[캐릭터 카드 붙여넣기]

위 캐릭터의 단독 기준 이미지를 그려주세요.
- 정면을 똑바로 보는 무릎 위 구도
- 차렷 자세, 팔은 자연스럽게 내림, 손이 얼굴이나 몸을 가리지 않음
- 무표정에 가까운 기본 표정, 입 다문 상태
- 균일하고 밝은 정면 조명, 강한 그림자 없음
- 순백색 단색 배경
- 캐릭터 1명만, 소품·텍스트·워터마크 없음
```

- 마음에 들 때까지 여러 장 뽑고 **1장만 확정**
- 확정 후 작은 오류는 편집 기능으로 수정 (다시 뽑지 않기)
- 이 이미지가 앞으로 모든 작업의 기준

## 5. 턴어라운드 시트 프롬프트 (기준 이미지 첨부)

**비율 16:9**

```
[이미지1]은 캐릭터 레퍼런스입니다. 얼굴, 헤어, 체형,
의상, 색상, 선화 스타일을 100% 동일하게 유지하세요.
[공통 그림체 문장]
[캐릭터 카드]

캐릭터 설정 시트를 만들어주세요.
- 가로로 긴 한 장에 전신 4개를 같은 크기로 나란히 배치
- 순서: 정면 / 3/4 측면 / 완전 측면 / 뒷모습
- 모든 포즈는 차렷 자세, 같은 키와 비율, 발끝이 같은 선에 맞춤
- 흰 배경, 균일한 조명, 텍스트·라벨 없음
```

---

## 6. 표정 시트 프롬프트 (기준 이미지 첨부)

**비율 1:1** · 턴어라운드와 한 장에 합치면 얼굴이 작아져 디테일이 무너지므로 **따로 생성**

```
[이미지1]은 캐릭터 레퍼런스입니다. 얼굴형, 눈, 헤어를
정확히 유지하세요.
[공통 그림체 문장]

같은 캐릭터의 표정 시트를 만들어주세요.
- 3x3 격자, 정면 얼굴 클로즈업(어깨 위) 9개
- 표정: 기본 / 미소 / 활짝 웃음 / 화남 / 슬픔 /
  놀람 / 당황 / 부끄러움(볼 홍조) / 진지함
- 모든 칸 같은 얼굴 크기와 각도
- 흰 배경, 텍스트 없음
```

> 웹툰 연출용 표정이 더 필요하면 `울음 / 비웃음 / 졸림 / 겁먹음 / 결의` 등으로 두 번째 시트를 추가

## 7. 의상 바리에이션 시트 (선택)

교복·잠옷·외출복 등 **의상이 바뀌는 회차**가 있다면 미리 만들어두기

```
[이미지1]은 캐릭터 레퍼런스입니다. 얼굴, 헤어, 체형은
그대로 유지하고 의상만 바꿔주세요.
[공통 그림체 문장]

같은 캐릭터의 의상 바리에이션 시트를 만들어주세요.
- 정면 전신 3개를 나란히 배치
- 의상1: (예: 남색 블레이저 교복, 체크 치마, 로퍼)
- 의상2: (예: 회색 맨투맨 잠옷, 수면 양말)
- 의상3: (예: 베이지 트렌치코트, 청바지, 앵클부츠)
- 흰 배경, 텍스트 없음
```

새 의상은 캐릭터 카드에 `의상_교복:` 처럼 줄을 추가해 기록

## 8. 파일 저장 규칙

```
하윤_A_00_기준.png
하윤_A_01_턴어라운드.png
하윤_A_02_표정.png
하윤_A_03_의상.png
도현_B_00_기준.png
...
```

- 캐릭터 카드 텍스트도 같은 폴더에 `하윤_A_카드.txt`로 저장
- 젠스파크 안에서 프로젝트/폴더 기능을 쓴다면 캐릭터별로 분리

## 9. 웹툰 컷 프롬프트

**비율 9:16 또는 3:4**

### 1인 컷
```
[이미지1] 하윤_A 기준 이미지
[이미지2] 하윤_A 턴어라운드 시트
[이미지3] 하윤_A 표정 시트
하윤_A의 외형을 레퍼런스와 정확히 동일하게 유지하세요.
절대 유지: 왼쪽 눈 밑 점, 은테 안경, 애쉬그레이 단발
[공통 그림체 문장]

샷: 바스트샷, 약간 아래에서 올려다보는 각도
장면: 해 질 녘 교실 창가, 창밖을 보다가 뒤돌아봄
표정: 표정 시트의 '놀람'
조명: 창으로 들어오는 주황빛 역광
말풍선·텍스트 넣지 않기
```

### 2인 이상 컷
```
[이미지1] 하윤_A 기준 이미지
[이미지2] 하윤_A 턴어라운드 시트
[이미지3] 도현_B 기준 이미지
[이미지4] 도현_B 턴어라운드 시트
두 캐릭터의 외형을 각각 정확히 유지하고 서로 섞지 마세요.
[공통 그림체 문장]

샷: 미디엄샷, 두 사람 모두 허리 위까지
배치: 하윤_A 화면 왼쪽, 도현_B 화면 오른쪽
장면: 비 오는 버스정류장, 하윤_A가 우산을 씌워주고
도현_B가 놀란 표정으로 올려다봄
말풍선·텍스트 넣지 않기
```

### 레퍼런스 배분 (최대 14장)
| 인원 | 캐릭터당 장수 | 구성 |
|---|---|---|
| 1명 | 3장 | 기준 + 턴어라운드 + 표정 |
| 2명 | 2~3장 | 기준 + 턴어라운드 (+ 표정) |
| 3~4명 | 2장 | 기준 + 턴어라운드 |
| 5명 이상 | 1~2장 | 한 컷에 다 넣기보다 **컷을 나누는 것 추천** |

> 배경 레퍼런스(같은 장소 반복 시)도 1장 추가하면 장소 일관성까지 유지됨

### 자주 쓰는 샷 용어
- 익스트림 클로즈업 (눈·입만) / 클로즈업 (얼굴) / 바스트샷 (가슴 위)
- 미디엄샷 (허리 위) / 풀샷 (전신) / 롱샷 (인물 작게, 배경 위주)
- 하이앵글 (위에서) / 로우앵글 (아래에서) / 오버숄더 (어깨 너머)

## 10. 말풍선·대사 처리

- AI 이미지에는 **말풍선과 대사를 넣지 않기** (글자 깨짐, 캐릭터 가림)
- 대사는 웹툰 편집 툴(클립스튜디오, 캔바, 젠스파크 AI 디자이너 등)에서 따로 얹기
- 컷 상단/하단에 말풍선 들어갈 **여백을 두고 싶으면**: `화면 위쪽 1/4은 비어 있는 하늘로 남겨주세요` 처럼 지시

## 11. 문제 해결

| 증상 | 해결 |
|---|---|
| 얼굴이 조금씩 달라짐 | 기준 이미지를 항상 [이미지1]로 첨부, "절대 유지" 줄 추가 |
| 헤어/옷 색이 바뀜 | HEX 코드 명시, 편집 기능으로 해당 부분만 수정 |
| 여러 캐릭터가 섞임 | 이미지마다 캐릭터 ID 명시, 화면 위치(왼쪽/오른쪽) 지정, 의상 색 대비 강화 |
| 그림체가 달라짐 | 모델 자동 선택 끄고 같은 모델 고정, 공통 그림체 문장 복붙 확인 |
| 고유 특징(점·안경)이 사라짐 | "절대 유지" 줄에 넣고, 클로즈업 컷에서 특히 확인 |
| 뒷모습/측면이 어색함 | 턴어라운드 시트를 반드시 같이 첨부 |
| 거의 맞는데 한 부분만 틀림 | 다시 뽑지 말고 **선택 영역 편집**으로 그 부분만 수정 |

## 12. 컷 생성 전 체크리스트

- [ ] 모델이 처음 정한 모델과 같은가?
- [ ] 각 캐릭터의 기준 이미지를 첨부했는가?
- [ ] 이미지마다 캐릭터 ID와 역할(기준/턴어라운드/표정)을 적었는가?
- [ ] 공통 그림체 문장을 그대로 붙였는가?
- [ ] "절대 유지" 항목을 넣었는가?
- [ ] 샷 크기·각도·배치·표정을 적었는가?
- [ ] "말풍선·텍스트 넣지 않기"를 넣었는가?
- [ ] 비율이 웹툰용(9:16 또는 3:4)인가?
