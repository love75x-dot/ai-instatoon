# 페이지별 사람 검토 체크리스트

생성: 2026-10-01 · 상태: **AI가 작성한 초안, 사람 검토 미완료** (AI의 재검사는 사람 검토가 아님)

각 페이지에서 확인할 것: ① 본문 정확성 ② 출처·권리(이미지·인용·외부 서비스 기능) ③ 실제 경험·자격 표현(지어낸 사례/후기 없음, 가상 사례는 "가상" 표시) ④ 사이트 적합성 ⑤ 추가 가치의 근거

질문: "누가 어떤 문제를 해결하도록 돕는가? 일반적인 설명에 어떤 실질적 가치를 더했으며 근거는 무엇인가?"
