인스타툰 연재실은 이렇게 써요

가게 업종과 있었던 일을 적으면 인스타툰 대본, 컷별 그림 프롬프트, 인스타그램 캡션과 해시태그 초안을 정리해 주는 도구예요. 대본과 글은 Gemini(본인의 API 키 필요)가 만들고, 그림은 ChatGPT 같은 외부 이미지 도구에서 직접 만들어 올려요.

  1. 가게 이야기 적기 — 업종만 골라도 시작할 수 있어요.
  2. 대본 다듬기 — 컷별 대사와 제목을 고치고 가격·시간 같은 숫자를 확인해요.
  3. 그림 올리기·저장 — 완성 그림을 zip으로 저장하고 캡션을 복사해 인스타그램에 올려요.
